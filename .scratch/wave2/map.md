# Map: LuiQuest Wave 2 — ทำแอพให้สมบูรณ์ + เปิดเก็บเงินจริง

Label: execution map (ฟอร์แมตเดียวกับ `../build-wave1/map.md` — wayfinder ถูกถอดออกจากเครื่องแล้ว ใช้ไฟล์นี้เป็น tracker มือ)
เปิด: 4 ส.ค. 2026

## Destination

**แอพที่ "สมบูรณ์พอจะประกาศเต็มตัว" + มีคนจ่ายเงินจริง** — ไม่ใช่แค่รันได้:

1. **เก็บเงินได้จริง** — ผู้ใช้กดสมัคร Premium 39 บาท/เดือน → PromptPay QR → อัปสลิป → เจ้าของกด verify → ได้สิทธิ์จริง; มีผู้จ่าย M ≥ 3–5 คน
2. **เนื้อหา/roadmap ตรงและมีประโยชน์จริง** — คนเรียนตามแล้วรู้สึกว่า "ได้ของ" ไม่ใช่ลิงก์มั่ว ๆ หรือลำดับสุ่ม
3. **หน้าตาน่าใช้** — คนเปิดครั้งแรกแล้วอยากเล่นต่อ ไม่ใช่แค่ "ใช้ได้"
4. **Wave 1 ปิดสนิท** — เช็คลิสต์ ticket 11 ครบ, DB เริ่มนับศูนย์, ไม่มีบั๊กระดับ P0 ค้าง

ถึงจุดหมายเมื่อ: คนแปลกหน้าเปิดลิงก์ → สมัคร → เรียนได้จริงหลายวัน → มีบางคนยอมจ่าย 39 บาท และตัวเลขทั้งหมดพิสูจน์ได้จาก DB

## Notes

- **สเปกที่ล็อกแล้วคือแหล่งความจริงเดียว** — ระบบเก็บเงินออกแบบจบแล้วใน [`../app-v2-spec/spec.md`](../app-v2-spec/spec.md) §6 (BMC, เส้นแบ่งฟรี/จ่าย, flow PromptPay 6 ขั้น, กฎเหล็ก paywall) **ห้าม re-decide** — Wave 2 คือ "สร้างตามที่ล็อก" ไม่ใช่ "ออกแบบใหม่"
- **`payments` table มีใน `supabase/schema.sql:371` แล้ว** และ gating บางส่วนต่อไว้แล้ว (`chat.js` แยก `PREMIUM_DAILY_LIMIT=100`, `questGenerator.js:87-88` ให้ premium ข้ามเพดานหัวข้อ) → งานที่เหลือคือ function + UI + หน้า admin ไม่ใช่ schema
- **ข้อจำกัดตายตัวไม่เปลี่ยน:** free tier ล้วน (Supabase / Netlify / Gemini) — PromptPay บุคคลไม่มีค่าธรรมเนียม, QR generate ฝั่ง client จาก payload EMVCo **ห้ามใช้ payment API ที่เสียเงิน**
- **โควตา Gemini ≈ 560 requests/วันทั้งแอพ** เป็นเพดานจริง — ทุกข้อเสนอที่เพิ่ม request ต่อผู้ใช้ต้องบอกต้นทุนเป็นจำนวน request
- **แบ่งงาน:** Claude สั่ง/ตรวจ + Codex (gpt-5.6) รับงานอ่าน/รีวิว/เขียนเทส/แก้ backend ที่มีเทสรองรับ — guardrail: ห้ามแตะ git, แก้เฉพาะบรรทัดที่จำเป็น ห้าม reformat, ต้องเขียนเทสมาด้วย, Claude เช็ค diffstat ก่อน commit ทุกครั้ง (เคสเตือน: Codex เคยรื้อ component เพื่อน 574→27 บรรทัด)
- **Codex ไม่มีเน็ต** — งานที่ต้องยิง production / Supabase / Gemini / เบราว์เซอร์ ทำเองเท่านั้น ห้าม delegate
- **มี agent อีกตัวทำงานคู่ขนาน** (e2e OAuth + PWA test) — เช็ค `git status` ก่อน commit ทุกครั้ง
